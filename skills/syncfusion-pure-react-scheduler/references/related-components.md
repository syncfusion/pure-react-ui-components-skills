# Syncfusion Pure React Documentation

This is the documentation for Syncfusion Pure React Components.
It includes usage guides, examples, and features for building React user interfaces.

## UI-Components

- [Autocomplete](https://react.syncfusion.com/react-ui/autocomplete.md): The React Autocomplete component is an intelligent text input field with dynamic suggestions that appear as users type.
- [Button](https://react.syncfusion.com/react-ui/button.md): The React Button component is a versatile user interface element designed for creating interactive buttons in web applications.
- [Calendar](https://react.syncfusion.com/react-ui/calendar.md): The React Calendar component provides an intuitive interface for date selection and navigation.
- [Checkbox](https://react.syncfusion.com/react-ui/checkbox.md): The Checkbox component is a versatile UI element enabling binary selections in forms, with customizable colors for enhanced clarity.
- [Chip](https://react.syncfusion.com/react-ui/chip.md): The React Chip component is a versatile, compact UI element that represents discrete information, attributes, or actions in an easily recognizable format.
- [Chiplist](https://react.syncfusion.com/react-ui/chiplist.md): The ChipList component is a specialized container that manages collections of Chip elements in a cohesive, organized manner.
- [Combobox](https://react.syncfusion.com/react-ui/combobox.md): The React ComboBox component is an editable input with an associated list of suggestions.
- [Context Menu](https://react.syncfusion.com/react-ui/context-menu.md): The ContextMenu component provides a popup menu that appears when a user interacts with an element through right-click or a long press action.
- [Datepicker](https://react.syncfusion.com/react-ui/datepicker.md): The React DatePicker component provides an intuitive interface for date selection and navigation.
- [Daterangepicker](https://react.syncfusion.com/react-ui/daterangepicker.md): The DateRangePicker component allows selection of a start and end date as a continuous range.
- [Datetimepicker](https://react.syncfusion.com/react-ui/datetimepicker.md): The React DateTimePicker component provides a unified input to select both date and time.
- [Dialog](https://react.syncfusion.com/react-ui/dialog.md): The React Dialog component is a pop-up window that appears in front of app content to show important information, collecting user input, showing forms, or presenting detailed content.
- [Dropdown Button](https://react.syncfusion.com/react-ui/dropdown-button.md): The React Dropdown Button is a graphical user interface component that displays Dropdown Buttons  with visual severity levels.
- [Dropdown List](https://react.syncfusion.com/react-ui/dropdown-list.md): The React Dropdown List component is a user interface element that allows users to select a single option from a list of predefined options.
- [Floating Action Button](https://react.syncfusion.com/react-ui/floating-action-button.md): The Floating Action Button (FAB) enhances accessibility with its floating design and customizable icons and colors for context.
- [Form](https://react.syncfusion.com/react-ui/form.md): The Form is a powerful validation tool for React applications that helps manage form state and validation rules.
- [Listview](https://react.syncfusion.com/react-ui/listview.md): The React ListView component displays data in an interactive hierarchical interface across different layouts or views and includes features such as data binding, template rendering, and grouping.
- [Menu](https://react.syncfusion.com/react-ui/menu.md): The Menu component provides a flexible navigation system for displaying commands, application navigation, and hierarchical menu structures.
- [Message](https://react.syncfusion.com/react-ui/message.md): The React Message is a graphical user interface component that displays messages with visual severity levels.
- [Multiselect](https://react.syncfusion.com/react-ui/multiselect.md): The React MultiSelect Dropdown with Tags enables the selection of multiple options with filtering, custom values, grouped items, and full accessibility.
- [Numeric Textbox](https://react.syncfusion.com/react-ui/numeric-textbox.md): The Numeric TextBox is a specialized input control for precise and flexible numeric data entry in web applications.
- [Radio Button](https://react.syncfusion.com/react-ui/radio-button.md): Radio Button are key UI components that let users select a single option from predefined choices, often found in forms and surveys.
- [Skeleton](https://react.syncfusion.com/react-ui/skeleton.md): The Skeleton component enhances user engagement by improving loading states during data retrieval.
- [Spinner](https://react.syncfusion.com/react-ui/spinner.md): The Spinner component displays a loading indicator to represent ongoing background operations.
- [Split Button](https://react.syncfusion.com/react-ui/split-button.md): The React Split Button is a graphical user interface component that displays Split Button with visual severity levels.
- [Switch](https://react.syncfusion.com/react-ui/switch.md): The Switch component is a binary toggle control enabling users to switch between ON and OFF states with customizable icons, labels, and colors.
- [Telemetry](https://react.syncfusion.com/react-ui/telemetry.md): Syncfusion Telemetry collects anonymous usage information to help improve product quality, usability, and feature planning for Pure React components.
- [Textarea](https://react.syncfusion.com/react-ui/textarea.md): The TextArea component enables users to enter and display multiple lines of text.
- [Textbox](https://react.syncfusion.com/react-ui/textbox.md): The TextBox component is a lightweight component that can be used to get input from users in various forms such as text, password, email, etc.
- [Timepicker](https://react.syncfusion.com/react-ui/timepicker.md): The React TimePicker component is a user interface control that enables users to select or input time values in a structured and interactive way.
- [Toast](https://react.syncfusion.com/react-ui/toast.md): The Toast component offers a seamless way to notify users without disrupting their workflow, appearing briefly before disappearing automatically.
- [Toolbar](https://react.syncfusion.com/react-ui/toolbar.md): The React Toolbar component is a feature-rich container that organizes buttons, input, and custom elements in a horizontal or vertical layout.
- [Tooltip](https://react.syncfusion.com/react-ui/tooltip.md): The Tooltip component provides contextual information when users interact with elements on your application.

## Common Features

- [Accessibility](https://react.syncfusion.com/react-ui/common-features/accessibility.md): Accessibility ensures that user interface elements are usable by people with disabilities.
- [Animation](https://react.syncfusion.com/react-ui/common-features/animation.md): Syncfusion React Animation components provide smooth and customizable animation effects for HTML elements by running sequences of frames, with support for various animation types, timing functions, and event handling.
- [Controlled Mode](https://react.syncfusion.com/react-ui/common-features/controlled-mode.md): React provides two main approaches for managing component state and handling user input through controlled and uncontrolled components.
- [Drag And Drop](https://react.syncfusion.com/react-ui/common-features/drag-and-drop.md): Drag-and-drop is an intuitive interaction pattern that allows users to click and hold an element, move it across the interface, and release it at a target location.
- [Globalization](https://react.syncfusion.com/react-ui/common-features/globalization.md): Globalization helps your app work for users in different languages, regions, and writing systems.
- [Internationalization](https://react.syncfusion.com/react-ui/common-features/internationalization.md): Internationalization (I18n) controls how dates, numbers, percentages, and currencies are formatted and parsed according to a specific culture.
- [Localization](https://react.syncfusion.com/react-ui/common-features/localization.md): Localization (L10N) adapts the user-facing text in Syncfusion React components to a specific language or region.
- [Right To Left](https://react.syncfusion.com/react-ui/common-features/right-to-left.md): Right-to-Left (RTL) support enables applications to communicate effectively with users who read languages from right to left, such as Arabic and Hebrew.
- [Security](https://react.syncfusion.com/react-ui/common-features/security.md): Security is a crucial aspect of web application development, aimed at protecting applications from a wide range of threats and vulnerabilities.
